PointerEvent

class PointerEvent(val type: PointerEventType, val x: Int, val y: Int, val button: PointerButton = PointerButton.None, val scrollDelta: Int = 0, val shift: Boolean = false, val alt: Boolean = false, val ctrl: Boolean = false, val isWithinBounds: Boolean = true)

An event of the mouse pointer at x and y, relative to the top left of the node which receives it. Coordinates can be outside of the node for drags and releases, which go to the nodes the press went to.
