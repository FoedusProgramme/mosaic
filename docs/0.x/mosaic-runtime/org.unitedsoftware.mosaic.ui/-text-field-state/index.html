TextFieldState

@Stable
class TextFieldState(initialText: String = "")

The editable text of a TextField, the position of its cursor, and its selection.

The cursor is an index into text between two characters, where 0 is before the first one and the length of text is after the last one. The selection reaches from where it started, its anchor, to the cursor. Without a selection, the anchor is at the cursor.

Edits are recorded so that undo and redo can step through them, with typed characters grouped by word.
