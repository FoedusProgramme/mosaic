TextField

@Composable
fun TextField(state: TextFieldState, modifier: Modifier = Modifier, focused: Boolean = true, singleLine: Boolean = false, maxLines: Int = Int.MAX_VALUE, placeholder: String = "", color: Color = Color.Unspecified, placeholderColor: Color = Color.Unspecified, textStyle: TextStyle = TextStyle.Unspecified, onSubmit: (text: String) -> Unit? = null)

An editable text field.

While focused, key presses and pastes edit state, and the terminal's cursor is placed at its cursor so that input methods show their composition there. Text is wrapped to the width of the field, at spaces where possible, and at most maxLines lines are shown, scrolled to keep the cursor visible.

When onSubmit is set, Enter calls it with the text. Otherwise, and with Shift+Enter or Alt+Enter, it inserts a line break unless this is singleLine. Pasted line breaks become spaces in a singleLine field.

The usual editing keys work, along with Ctrl+A and Ctrl+E for the start and end of the line, Ctrl+U and Ctrl+K to delete to them, and Ctrl+W to delete the previous word.
